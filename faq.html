Clear answers about VEXO Hub

Learn how the application organizes information, protects local data and handles the features you choose to use.

VEXO Hub is a personal organization application for notes, documents, reminders, warranties, maintenance records and other important information. It brings these records together inside one searchable workspace.

Yes. Core organization features use a local, offline-first workspace. Network access is required only for features that inherently depend on an online provider, such as account authentication or future cloud services.

Your VEXO Hub workspace is stored in the application’s private local storage on your device. VEXO Hub does not expose its database to other applications.

Yes. Guest mode creates a local workspace for use on the current device. You remain responsible for exporting a secure backup if you need to preserve or move guest data.

VEXO Hub creates a backup file and a separate SHA-256 checksum file. Export and store both together. During import, VEXO Hub validates the matching checksum before restoring the backup.

No. Local backup export is an explicit user action. You choose the destination through Android’s secure sharing interface. Future cloud services will be documented before they are introduced.

VEXO Hub may request notification permission for reminders and temporary access to a photo, camera output or selected file when you choose to add an attachment. Permissions are requested in context and can be managed in Android settings.
